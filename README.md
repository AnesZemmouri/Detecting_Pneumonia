# DenseNet Chest X-Ray Pneumonia Classification

A TensorFlow/Keras computer vision project for classifying chest X-ray images as `NORMAL` or `PNEUMONIA`.

The notebook contains both:

- A small DenseNet implementation built from scratch to demonstrate dense connections.
- A pretrained DenseNet-121 model fine-tuned for chest X-ray classification.

## Project Contents

| File | Description |
| --- | --- |
| `DenseNetTF (1).ipynb` | Complete data preparation, training, evaluation, visualization, and inference notebook |
| `best_densenet_xray.keras` | Best saved model, generated after training; not included by default |
| `dense_connections.png` | DenseNet and ResNet connection comparison, generated by the notebook |
| `training_curves.png` | Training and validation curves, generated by the notebook |
| `confusion_matrix.png` | Test confusion matrix, generated by the notebook |

## Dataset

This project uses the [Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia) dataset from Kaggle.

The expected directory structure is:

```text
chest_xray/
├── train/
│   ├── NORMAL/
│   └── PNEUMONIA/
├── val/
│   ├── NORMAL/
│   └── PNEUMONIA/
└── test/
    ├── NORMAL/
    └── PNEUMONIA/
```

The notebook downloads the dataset with `kagglehub`. A Kaggle account and valid Kaggle access may be required.


For GPU training, install a TensorFlow version compatible with your operating system and CUDA setup.

## Running the Project

1. Open `DenseNetTF (1).ipynb` in Jupyter, Google Colab, or VS Code.
2. Run the imports and reproducibility setup cell.
3. Download or configure the dataset path.
4. Run the data-loading and visualization cells.
5. Train the classifier in two phases:
   - Phase 1: train the new classification head while DenseNet-121 is frozen.
   - Phase 2: unfreeze the final DenseNet block and fine-tune with a lower learning rate.
6. Run the evaluation cells to generate the classification report and confusion matrix.

The model uses 224 x 224 RGB images, ImageNet DenseNet preprocessing, data augmentation, class weights, early stopping, and model checkpointing.

## Inference

After training, the best model is saved as:

```text
best_densenet_xray.keras
```

The notebook provides a `predict_xray` function that accepts an image path and returns the predicted class and confidence scores:

```python
predicted_label, probabilities = predict_xray(
    "path/to/xray.jpg",
    model,
    CLASSES,
)
```
